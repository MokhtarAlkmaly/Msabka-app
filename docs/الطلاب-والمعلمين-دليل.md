# دليل صفحتي الطلاب والمعلمين والمعلمات (غير مرتبطتين بعام)

> آخر تحديث: 1447هـ — يشرح هذا الدليل كيف أصبح **سجل الطلاب** و**سجل المعلمين
> والمعلمات** صفحتين رئيسيتين مستقلتين تماماً عن الأعوام، وكيف توزّعت بقية
> الوظائف (الإكراميات، الشهادات، المساعدات العينية، الحلقات).

## 1) صفحة الطلاب — `/students`

- السجل الرسمي الشامل **لكل الأعوام** (نفس جدول الإدارة السابق)، ويظهر الآن
  كصفحة أساسية أولى في القائمة الجانبية باسم «الطلاب».
- المسار الرئيسي `/` يعرض نفس الصفحة أيضاً، فلم يتعطل أي رابط قديم.
- الإضافة والتعديل من الجدول تُحفظ في السجل الشامل مباشرة، ويُذكر لكل طالب
  «أعوام التسجيل» و«آخر حفظ تراكمي».
- لا يُربط الطالب بعام من هذه الصفحة؛ استدعاء الطلاب إلى عام/مسابقة يتم من
  صفحة «المسابقة الرمضانية» أو «إدارة الحلقات».
- **قسم «الاستيراد والتصدير» للسجل الشامل** في صفحة **«الإعدادات» (`/settings`)**
  قبل لوحة المزامنة والنسخ الاحتياطي، وليس في صفحة الطلاب، ويضم بطاقتين:
  - **استيراد سجل الطلاب**: تنزيل قالب Excel واستيراد دفعة طلاب إلى السجل
    الشامل (الاسم إلزامي فقط)، مع خيار تسجيل المستوردين في مسابقة العام النشط.
  - **تصدير السجل الشامل**: ملف Excel واحد بكل الطلاب وكل الأعمدة (الأساسية
    والمخصّصة).
  - في **وضع الاطلاع** يُعطَّل الاستيراد وتنزيل القالب وخيار التسجيل في العام،
    ويظهر تنبيه بذلك، بينما يبقى التصدير متاحاً.
  - أما تصدير نتائج بحث/تصفية محددة فمن زر «تصدير Excel» داخل الجدول،
    وطباعة السجل من زر «طباعة السجل» أو «PDF» بجانبه.
- **قسم «أدوات المسابقة»** في نفس الصفحة (بعد أدوات السجل الشامل وقبل لوحة
  المزامنة) — وهو المكان الجديد لأدوات **المسابقة** بعد نقلها من صفحة
  المسابقة:
  - اختيار **المسابقة** (الرمضانية أو عشر ذي الحجة) و**العام** أولاً، وتعمل
    كل الأدوات على هذا الاختيار (مفتاح العام `1447` أو `1447D`)، وهو نفس
    المفتاح الذي تقرأه صفحة المسابقة.
  - **استيراد سجل الطلاب** بنفس خيار تسجيل المستوردين في مسابقة العام
    المحدد، و**استيراد/تصدير بيانات المسابقة** (قالب Excel + تصدير الكشف +
    دمج الأسماء المكررة).
  - **حذف بيانات المسابقة**: حذف بيانات مسابقة عام كامل، أو فصل طلاب محددين
    منها، وكلاهما يبقي السجل العام للطالب. يتطلب كتابة عبارة تأكيد، ولا
    يشمل حذف قاعدة البيانات كاملاً (بقي في بطاقة «الحذف المتقدم» أسفل الصفحة).
  - في **وضع الاطلاع** تُعطَّل أدوات الاستيراد والحذف ويبقى التصدير متاحاً.
  - صفحة المسابقة تحتفظ بالحفظ والمزامنة والطباعة واستدعاء الطلاب وحذف
    الطالب من صفّه في الجدول، مع لافتة ورابط يفتحان الإعدادات.

## 2) صفحة المعلمين والمعلمات — `/teachers`

سجل **عام واحد لكل الأعوام**: يُضاف الاسم مرة واحدة ويظهر في كل الأعوام وفي
كل التبويبات، ولا يُطلب اختيار عام عند إضافة معلم/ة.

### التبويبات

| التبويب | ماذا يفعل | أين تُحفظ البيانات |
| --- | --- | --- |
| **السجل العام** | إضافة/تعديل/حذف الأسماء، وعرض عدد طلاب كل معلم/ة وأعوام حلقاتهم وإجماليات إكرامياتهم وشهاداتهم ومساعداتهم | جدول `teachers` بقيمة العام `all` |
| **الإكراميات الشهرية** | اختيار العام والشهر ثم إدخال مبلغ كل معلم/ة، وحفظ فردي أو جماعي، ونسخ مبالغ الشهر السابق كمسودة، وطباعة كشف العام (12 شهراً × المعلمين) | جدول `teacher_bonuses` |
| **الإكراميات السنوية** | إضافة/تعديل الإكرامية السنوية لكل معلم/ة، مع ملخص يجمع الشهرية + السنوية وطباعة تقرير | جدول `awards` بنوع `annual` |
| **شهادات التقدير** | إصدار شهادات تقدير للمعلمين والمعلمات، وتوليد شهادة شكر لكل من في السجل العام بضغطة واحدة، وطباعة الشهادات بتصميم جاهز | جدول `certificates` بفئة `teacher` |
| **المساعدات العينية** | تسجيل ما يُقدَّم للمعلمين والمعلمات من مساعدات عينية (كسوة، سلة غذائية، مستلزمات حلقات…) مع قيمتها التقديرية والجهة الممولة، وطباعة كشف | جدول `awards` بنوع عيني (`in_kind`) |

### تفاصيل مهمة

- **تعديل الاسم** يُحدّثه في: السجل العام، وخانة «المعلم/ة» عند الطلاب، وربط
  الحلقات في كل الأعوام، والإكراميات الشهرية، والجوائز السنوية والمساعدات
  العينية، والشهادات المرتبطة به.
- **حذف الاسم** يزيله من السجل العام، ويمكن (بعلامة اختيار مفعّلة افتراضياً)
  إزالته أيضاً من خانة «المعلم/ة» ومن ربط الحلقات في كل الأعوام.
- **الإكراميات والجوائز والشهادات هي نفس سجلات الصفحات العامة**، أي ما يُدخَل
  في تبويب «الإكراميات السنوية» يظهر في صفحة «الإكراميات والجوائز»، وما يُدخَل
  في تبويب «شهادات التقدير» يظهر في صفحة «الشهادات»، والعكس صحيح — بلا تكرار
  ولا نسخ بيانات.
- **وضع الاطلاع** (بيانات مستخدم آخر) يجعل الصفحة قراءة فقط كما في بقية الصفحات.

## 3) صفحة الحلقات — الترتيب لكل عام

- صفحة **الحلقات** هي المكان الذي يُرتَّب فيه المعلمون والمعلمات مع طلابهم.
- الأسماء تأتي من السجل العام (بلا عام)، أما **ربط الطالب بمعلم/ة** فيُحفظ لكل
  عام على حدة في بيانات العام (`year_data.teacher`)، فتبقى حلقات كل عام
  مستقلة وتاريخها محفوظاً.
- إضافة معلم/ة من صفحة الحلقات تُضيفه إلى السجل العام نفسه (بدل أن يكون
  مسجّلاً في عام واحد فقط).

## 4) صحة البيانات القديمة والتوافق

- المعلمون والمعلمات كانوا محفوظين لكل عام بصف مستقل. عند فتح صفحة المعلمين
  والمعلمات يُنفَّذ **توحيد تلقائي**: يُحوَّل كل صف قديم إلى صف عام واحد لكل اسم
  (بقيمة العام `all`)، وتُحذف الصفوف المكرّرة محلياً وسحابياً.
- لا حاجة إلى أي ترحيل SQL جديد: عمود `year` ما زال نصياً، والقيمة `all`
  مقبولة فيه، وقيود RLS لم تتغيّر.
- أسماء المعلمين المرتبطة بطلاب فقط (ولم تُضف للسجل العام) تظهر بشارة
  «من بيانات أخرى» مع زرّ تعديل لإضافتها.
- روابط المعلمين والمعلمات (`/teacher-links`) تُنشأ الآن لأي اسم في السجل
  العام (لكل الأعوام) بدل اشتراط إضافته لنفس العام.

## 5) الاختبارات

```sh
npm run test:teachers   # توحيد السجل العام، دمج الأسماء، تجميع الطلاب، الإجماليات
npm run test:community  # أقسام المركز ومسارات التنقل (تشمل /students و /teachers)
npm run test:sql        # قواعد البيانات والترحيلات
npm run lint
```

## 6) ما لم يتغيّر

بقية الصفحات (المتابعة الشهرية، المسابقة الرمضانية، الجوائز، الشهادات،
الداعمون، المصروفات، الوسائط، المستخدمون…) تعمل كما هي، مع نقل أدوات السجل
الشامل وأدوات المسابقة (الاستيراد/التصدير/الحذف) إلى الإعدادات كما ذُكر
أعلاه. وتستفيد الصفحات من سجل المعلمين العام:
قوائم أسماء المعلمين في هذه الصفحات أصبحت من السجل العام لكل الأعوام.
